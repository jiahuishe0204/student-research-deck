## 不能作为完成证据

- `/api/health` 正常；它不能证明 Worker 完成队列任务。
- `accepted:false/reason:empty`；它不能证明研究任务成功。
- GitHub Pages 或旧 EdgeOne 演示可打开；它不能证明生产登录和 P1—P9 可用。
- 已生成 ZIP；它不能证明 ZIP 已部署，也不能证明云端加载了该版本。
- 自动测试通过；它不能替代真实邮箱、数据库、COS 和端到端验收。

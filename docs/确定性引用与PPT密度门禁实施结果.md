# 确定性引用与PPT密度门禁实施结果

## 目标与验收标准

目标是解决两个已经通过真实实验确认的问题：模型可能用同来源的其他证据替错误引用开脱；科学修订可能把PPT变成不可演示的长文档。

本阶段验收标准为：固定10条声明离线回放达到85分以上，支持状态至少8/10、处理动作至少9/10、严重错误和虚构证据为0；PPT对平均字数、单页字数、单条字数、条目数和备注长度实施硬校验；所有测试通过；不产生新的DeepSeek费用。

## 已实施规则

### 当前引用优先

模型输出的有效证据必须与声明当前绑定的证据编号至少有一个交集。若模型只找到同来源的其他证据：

- 当前已有引用时，原声明按不支持和删除处理，同时记录引用缺失与来源错配。
- 当前没有引用时，声明按无法判断和标记未核实处理。
- 同来源其他证据只保留在解释中作为补引建议，不能把原引用判为合格。

这是一道模型输出后的确定性门禁，因此不依赖模型是否理解提示词，也不增加Tokens。

### PPT密度门禁

P6提示词和P6/P9验证同时使用以下标准：全稿平均不超过180字/页，单页不超过220字，单条不超过80字，每页不超过5条，备注不超过350字。

P9遇到超过页面承载能力的长修订时，不再把全文直接塞进幻灯片，而是在页面显示“该结论已按证据限定，完整修订见备注”，完整修订进入备注。若原始页面本身已经过密，系统拒绝生成终稿，要求重新编排，而不是自动截断科学内容。

## 离线回放结果

使用增强Flash已经保存的真实输出回放，没有再次调用模型，也没有新增费用。

- 总分：78分提高到94分。
- 支持状态：8/10提高到10/10。
- 处理动作：8/10提高到10/10。
- 严重错误：1降为0。
- 虚构证据：保持0。
- 有效证据项：9/10；CLM-0021仍需要后续改善证据组合，但不构成严重错误。

旧基线PPT因单页超过220字被门禁拦截；科学修订版因单条超过80字被拦截。门禁没有把旧结果误报为通过。

## 三审结论

一审工程：通过。引用门禁在模型调用之后、终稿装配之前生效，零Token；74项测试全部通过。

二审科学：通过本阶段门槛。固定样本达到94分且严重错误为0。仍需保留CLM-0021的证据组合问题作为普通改进项，不能据此声称所有主题已经完成科学验证。

三审呈现：门禁通过，旧内容未通过。系统已经能够拒绝过密PPT，但还需要重新生成或重新编排一份真正满足密度标准的内容包，才能完成产品呈现验收。

## 下一步

1. 使用现有报告和证据重新生成P6内容包，并受密度门禁约束。
2. 先做一次离线装配与密度检查；只有P6确实需要模型重写时才启用付费调用。
3. 对通过密度门禁的新PPT进行可读性人工抽查，避免仅靠字数得到内容空洞的页面。
4. 最后再决定是否进行一次受控Flash复验；该复验不是本阶段通过的前提。

# PPT内容质量验收标准

## 作品目标

PPT要帮助学生把研究讲清楚、讲得可信，并能应对老师、同学或上级的追问。字数少不是目标，信息能够被理解、记住和复述才是目标。

## 五项核心标准

### 1. 主线与结论，20分

开场提出真实问题；中间内容按逻辑推进；结尾能够回扣问题。每页只承担一个主要沟通任务，标题尽量表达判断，而不是只写名词。

### 2. 听众理解，20分

第一次接触主题的听众能理解关键术语、案例之间的关系以及为什么这些内容重要。学生不依赖逐字朗读也能完成讲解。

### 3. 分析深度，20分

不只罗列数字，还解释工程手段解决了什么瓶颈、证据能支持到什么程度、哪些结论不能外推。至少形成一个可迁移的分析框架。

### 4. 证据与可信度，20分

关键数字和判断可追溯；观察结果、机制解释和产业化判断分层表达；没有证据的内容明确标为未知，不用漂亮话补足。

### 5. 可讲性与视觉任务，20分

页面有明确的视觉表达建议，关键数字容易被看到，案例页不是大段文字。详细条件进入备注，但决定结论含义的限定不能被隐藏或删除。

总分85分为内容包通过线，且证据与可信度不得低于17分。真正生成PPTX后，还需检查字号、对齐、颜色对比、图表准确性和投影可见性；内容包通过不等于视觉成品已经通过。

## 密度的正确角色

密度用于发现极端堆字，不直接决定作品质量。常规页面可以3—5个要点，数据页可适度增加；机器只拦截接近正文段落的异常情况。最终判断还要看信息层级、视觉组织、讲解时间和听众背景。

## v2内容包复盘

- 主线与结论：18/20。形成“问题—评价框架—三种路径—三个案例—放大边界—结论”的闭环。
- 听众理解：18/20。新增评价框架和案例贡献说明，减少专业名词的无解释堆叠。
- 分析深度：18/20。不只给滴度，还解释机制证据、稳定性和产业化缺口。
- 证据与可信度：19/20。保留可追溯编号，明确摘要边界和不可外推项。
- 可讲性与视觉任务：17/20。每页已有视觉建议和讲解备注，但尚未生成实际PPTX，视觉效果仍需后续验证。

内容包暂评90/100，达到内容验收线；视觉成品尚未验收。

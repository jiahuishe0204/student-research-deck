# 资深学术型PPT与动态研究结构方案

## 目标

在现有本科生汇报版之外增加“资深学术版”。它不是简单增加术语或页数，而是先识别研究问题类型，再决定检索、论证和PPT结构；关键主张、数字、图表和限制必须可追溯。

## GitHub技能调研

### Research Slides

地址：https://github.com/xiaohan-2005/research-slides

最值得借鉴。它强调从论文、数据和研究笔记出发，维护“claim → source → evidence → slide”的链路，并区分报告发现、推导值、解释和背景。流程包含证据提取、声明账本、叙事设计、视觉选择与证据/结构/视觉验证。它也明确主张“叙事而不是转录”，并把真实论文图表视为证据而非装饰。

局限：项目标注为alpha，主要输出1920×1080 HTML deck，不等于我们当前的结构化内容包和未来可编辑PPTX。适合借鉴方法，不宜直接替换产品链路。

### Academic Slides / PPT Image

地址：https://github.com/FA-T-T/codex-skill-academic-slides

优点是参考资料优先、内容清单锁定事实、逐页视觉审查，并明确图像模型不能发明数据、引文、柱高和公式。适合未来制作Nature/Science风格的资深视觉版。

局限：依赖GPT Image 2后端，主要将每页做成图片再打包PPTX；视觉完成度高，但文本和图表的后续编辑性较弱，且会增加图像生成成本。当前不直接安装。

### Anthropic PPTX Skill

地址：https://github.com/anthropics/skills/blob/main/skills/pptx/SKILL.md

强项是PPTX读取、编辑、模板复用、缩略图检查和文件级装配。它解决“如何可靠地产生PPTX”，但不专门解决生命科学主题如何形成学术研究结构。

### Codex Research

地址：https://github.com/LIU-31415/codex-research

虽然不是PPT技能，但其“从当前决策与问题出发、按证据类型调整研究路径、摘要只用于发现而非高强度结论”的原则非常适合资深学术版的前置研究规划。

## 调研结论

不直接安装第三方技能。当前最合理的组合是：吸收Research Slides的证据链和研究叙事方法，吸收Academic Slides的真实图表优先与视觉复核边界，继续使用本项目已经实现的声明核验、费用保护和P1—P9工作流。等真正开始生成PPTX时，再单独评估文件装配技能。

## 动态研究结构

产品不再预设所有主题都使用同一目录。高级模型先识别以下研究类型，可选择一种或多种组合：

- 疾病或病理现象：定义与边界、疾病负担、自然史、病理生理、研究模型与测量、干预、证据阶段、争议与空白。
- 药物或治疗：靶点和机制、适应人群、疗效、安全性、对照、证据等级、临床阶段与监管。
- 诊断：临床场景、样本与金标准、敏感性/特异性、外部验证、可实施性和偏倚。
- 技术或方法：原理、工作流、性能指标、基准、适用条件、局限和复现。
- 机制：观察事实、候选因果链、关键节点、模型证据、替代解释和可证伪实验。
- 工程或平台：需求、架构、瓶颈、工程策略、性能、稳定性、放大和转化。
- 比较评估：共同问题、统一比较维度、证据可比性、权衡和适用场景。
- 转化与产业化：技术成熟度、生产、成本、知识产权、监管、采用障碍和验证路径。

P2只选当前主题必要的模块。PPT结构必须从研究问题和证据类型产生，不能把模块库完整复制为目录。

## 心脏瓣膜钙化示例

对“心脏瓣膜钙化”，合理的资深版结构可以是：

1. 定义钙化及其与退行性瓣膜病变的关系。
2. 说明疾病负担、临床后果和目前治疗缺口。
3. 梳理细胞、分子、炎症、脂质与力学机制，并区分相关性和因果证据。
4. 比较组织学、影像、体外细胞、类器官和动物模型分别能回答什么。
5. 将药物、器械和其他干预按靶点与证据阶段组织，而不是列药名。
6. 区分前临床信号、观察性临床证据、随机试验和临床指南状态。
7. 总结失败原因、争议、关键研究空白和下一步可证伪问题。

这套结构只适用于疾病与干预混合主题，不应复制给合成生物学平台、诊断技术或专利格局研究。

## 已实施的产品调整

1. 快速版和深入版的P1/P2都使用更强模型，因为意图与框架决定全部下游质量；快速版用低思考和较小输出上限，深入版在P2使用高思考与更完整规划。
2. P1提示词要求识别研究类型，并在scope_hint中给出主题特异的展开维度。
3. P2提示词增加八类研究原型和心脏瓣膜钙化示例，明确禁止固定模板。
4. P2现在接收并保留真实P1意图，而不是重新构造一个只有主题名称的简化对象。
5. P6现在接收P2研究计划，必须继承主题特异的研究问题和叙事结构。
6. 版本差异改为证据规模、规划深度和输出预算，不再用较弱模型降低研究问题定义质量。

## 预算确定顺序

当前不直接按理论最大Tokens制定正式单题预算。先冻结提示词、结构协议、P1的1,800输出上限、快速P2的3,600上限和深入P2的6,500上限；再用四类固定主题各运行一次，记录实际输入、reasoning、正文、费用、重复问题和结构错配。预算以通过质量门槛的真实分布为依据，并预留可解释的失败余量，而不是把模型允许的最大输出全部当成日常成本。

低级模型不再作为P1/P2生产候选，因此四主题实验的目的不是证明高级模型优于低级模型，而是验证高级模型在提示词约束下是否稳定地产生不同且合适的框架，以及需要多少实际费用。

## 验收标准

供人工查看和讨论的完整版本见《四类研究框架验收样本（可读版）》。JSON样本仅供自动测试读取，不作为主要交付界面。

- 用至少四种不同研究原型测试，生成的研究问题和PPT结构不能只是换主题名。
- 疾病主题必须包含定义、机制/自然史、研究方法、干预证据阶段和空白中的相关模块。
- 技术主题必须包含性能指标、基准、适用条件与验证，不能套疾病结构。
- 工程主题必须围绕瓶颈、策略、性能、稳定性与放大。
- P6实际继承P2的ppt_story_arc，不能在后段丢失高级模型的规划结果。
- 高级模型只用于意图与规划等高价值节点，继续受任务级人民币停止器保护。

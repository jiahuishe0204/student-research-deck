# 调研交付台界面视觉一致性规则

## 适用范围

首页、题目确认、任务进行中、交付结果、引用与图源以及后续新增的客户可见页面，必须使用同一套视觉语言。样本页上的视觉修改若被确认，不得只保留在样本；应同步检查入口页、真实工作流页面、共用样式和相应回归测试。

## 已确认的视觉基线

- 整体采用浅色、低饱和度的紫灰色体系，不使用深黑或荧光绿色科技风。
- 页面背景使用暖白到浅紫灰的柔和层次；主要内容卡片使用白色。
- 主强调色使用克制的中等紫色，主要用于按钮、选中状态、目录滑块和少量状态提示。
- 正文和控件使用清晰的无衬线字体；大标题使用宋体类衬线字体，保持交付阅读页的编辑感。
- 圆角、边框、阴影、按钮、输入框和选中状态应与交付结果页保持一致，不为首页另建一套视觉主题。
- 品牌图标统一使用紫底白色的打开书页符号，不再使用字母圆章或雪花状图标。
- 动效应服务于状态切换和导航关系，使用先加速后减速的缓动；避免元素从页面左上角飞入。
- 首页的暖白—浅紫渐变是客户界面的背景基线；结果页保留白色阅读卡片，但卡片外背景应继承同一渐变和柔和光感。
- 外观上像分页或目录的控件必须真实可操作。首页交付预览中的页面编号应能切换对应内容、讲稿和来源，并提供明确的选中反馈与切换动效。
- 首页“问题／路线／证据”的交互样式作为二级目录基线：浅紫柔光渐变选中背景、轻微阴影、文字状态变化，以及内容沿目录方向轻微上下切换。交付页的报告目录、PPT页面目录和“全部／论文来源／图源”筛选应复用这一语言。选中项不再叠加左侧紫色竖线，以免在窄目录中显得拥挤。
- 并列流程卡片的编号、标题和正文分别对齐；不得因标题行数不同造成01、03等同级项目出现视觉错位。
- 桌面和平板宽度下，四步工作流程必须平均分成四个独立等宽模块，不使用两列两行的“T字型”分组；每一步都有完整轻边框、圆角和一致内边距。仅在手机窄屏下改为单列。
- 版本价格卡片底部的价格信息必须保持单行：标签、主价格和补充单位不得拆成上下两行；窄屏通过字号和间距自适应处理。

## 工程执行规则

1. 客户可见页面的视觉改动必须同时判断是“当前样本特例”还是“产品通用规则”。通用规则应写入共用样式或本文件，并增加离线检查。
2. 结果页确认的颜色、字体、品牌和控件语言默认视为产品基线；新增页面应继承，而不是重新设计。
3. 每次只修改样本内容而未同步生成规则时，交付说明必须明确标注“仅当前样本”；不得让用户误以为下一次生成也已修复。
4. 修改完成后至少检查桌面宽度、手机宽度、直接打开本地文件和通过本地服务打开四种场景。

# 合成生物学发酵同题成本质量对照

更新时间：2026-10-08

## 实验设计

基线任务为 `TASK-8ac42e4ee030`，对照任务为 `TASK-c3ec0391d47e`。为隔离核验规则的影响，对照任务复用同一主题已经固定的来源、证据、报告、PPT和75条声明，只重新执行P8并用零Token的确定性P9装配终稿。

本轮设置人民币金额、全任务Tokens、Pro付费次数、Pro输出和Pro总Tokens五类请求前停止器。实验过程中产生的所有成功、格式拒绝、空输出和网络错误均写入账本。

## 实际费用与用量

第一次工程探测因Pro high思考占满输出而停止，实际费用为¥0.10498622。

完成对照任务实际费用为¥0.31214326，使用146,616 Tokens：Flash 125,185，Pro 21,431。Flash有20次成功输出、2次格式拒绝；Pro有1次成功输出、3次空输出和1次零Tokens网络错误。由于Pro成功结果所在的大请求最终失败，它没有进入最终交付；最终交付中65条声明来自本轮Flash重验，10条关键声明明确复用原基线核验。

两轮实验实际合计¥0.41712948，没有超过¥0.50实验上限。旧版完整同主题任务费用为¥3.14948702；本次范围只覆盖P8/P9并复用P1—P7，不能把86.75%的金额下降全部归因于模型优化，但可以确认在固定草稿上重新生成完整核验终稿的增量费用已显著下降。

## 输出变化

报告仍为22个标题层级，正文由3,932字增加到4,091字，增加159字。

PPT仍为12页。上屏文字由2,343字增加到2,881字，增加538字；演讲备注由1,134字增加到1,313字，增加179字。

核验结果从45条支持、23条部分支持、0条不支持、7条无法判断，变化为33条支持、33条部分支持、4条不支持、5条无法判断。最终动作从43条保留、25条修订、0条删除、7条未核实，变化为29条保留、37条修订、4条删除、5条未核实。两版高风险遗留均为0。

新版更严格地识别了对象外推、因果过度、摘要证据边界和错误证据编号。例如：不再把“优化NADPH与血红素供应”写成已经直接测量相关水平；把视觉建议中的“摘要级证据”限定语真正写入幻灯片；删除缺乏证据的一般化流程或经济性断言。

## 是否更详细、更美观

更详细：是。报告、上屏文字和备注均增加，而且新增内容主要是证据条件、适用边界与核验修订，不是重复扩写。

更可靠：是。部分支持和删除数量增加，说明新版没有为了保持原文而放过证据范围问题。

更美观：不能直接认定。页数和故事线未改变，部分页面文字明显变密，尤其第11页增加约305字。它提升的是严谨性和可追溯性，但可能降低视觉简洁度。下一步应把长核验说明移入备注或附录，在不删除关键限定语的前提下压缩上屏文字。

## 本轮暴露并解决的工程问题

1. 固定四条并不天然省钱；真正有效的是动态分批加按引用裁剪证据。
2. Pro high思考会在较小输出上限下把Tokens全部花在reasoning，得到空正文；结构化核验改为low思考。
3. 零Tokens网络失败不应消耗Pro付费次数，因此分离“尝试次数”和“付费调用次数”。
4. 大请求中后段失败会让前段成功结果丢失，因此改为动态小批逐批持久化。
5. 单纯Tokens上限不能等价为人民币预算，因此新增按官方峰谷价的金额硬停止器。
6. P7位置字段可能与实际PPT字段不一致；P9现在可在同页正文、备注和视觉建议之间保守定位，但仍找不到时继续拒绝假完成。

## 决策

动态分批、证据裁剪、本地JSON修复、逐调用账本、逐批检查点和人民币停止器保留。

暂不把本轮数据直接冻结为正式产品预算。Pro在结构化核验中仍出现较高空输出比例；下一步应使用固定10条关键声明做一次独立Flash/Pro质量实验，而不是再次运行整题。PPT还需要新增“上屏文字密度”验收，避免严谨性改进演变成页面过载。

## 排障与方法沉淀

1. **测试按钮点击后迟迟没有结果**：SCF 是异步执行。先看 Request ID 和状态，不以“按钮已点”当作成功；本轮用最终 `status: succeeded`、运行时长和返回结果确认完成。
2. **控制台测试输入框容易误选页面或代码编辑器**：页面滚动位置会影响 AX 元素定位。改为先观察实际测试面板，再用坐标点入事件 JSON 编辑框，粘贴后只点“测试”，不点“部署”；每步提交后重新读取状态。这样避免把测试 JSON 写进函数源代码或误发布代码。
3. **响应日志被 UI 截短**：下游只传契约所需的最小 JSON，并保留摘要级限制；同时在记录中明确“重建输入”。这能继续验证下游函数，但不能被描述成原始响应无损流转。下一步应增加可下载/可复制的完整测试结果或通过受控 API 自动串接阶段输出，再跑一次真正的 P2→P9 集成回归。
4. **单阶段事件不会自动串接**：阶段注册表及分发器要求每次输入当前阶段依赖字段，测试器不会自动读取上一步输出。因此 P2–P9 手工逐段触发时，需要明确区分“阶段冒烟通过”和“端到端工作流通过”。

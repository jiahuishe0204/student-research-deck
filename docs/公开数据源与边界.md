# 公开数据源与边界

## 当前 MVP

- PubMed：使用 NCBI E-utilities 的 ESearch + EFetch XML，单次批量读取 PMID、DOI、标题、摘要、作者、期刊和年份。未配置 NCBI API key 时必须保持每秒不超过 3 个请求；当前每次检索只有两个串行请求。
- Europe PMC：使用 REST Search JSON 和 `resultType=core`，获取摘要、全文可用状态和文献元数据。
- Crossref：使用公开 REST `/works` 检索学术元数据。如果配置 `RESEARCH_CONTACT_EMAIL`，服务会自动加入 `mailto` 参数使用 polite pool；未配置时不会伪造联系方式。

## 去重和降级

1. 先用 DOI，再用 PMID，最后使用规范化标题去重。
2. 同一条记录出现在多个来源时，保留来源列表，并优先保留更完整的摘要。
3. 任一来源失败时，返回其他来源并显示失败来源，不把部分结果冒充完整结果。
4. Crossref 是元数据来源，不单独支撑科学结论。

## 版权和生产限制

- PubMed 摘要可能包含受版权保护的内容，界面必须显示 NCBI Disclaimer and Copyright 链接，不对外批量分发摘要全文。
- Europe PMC 的全文状态不等于所有素材都可自由复制；图片复用必须另外记录许可证状态。
- Crossref 的大部分元数据可重用，但其中的摘要仍可能受出版商或作者版权保护。
- 公开免费 API 不提供生产 SLA；公开投放前需决定缓存、重试、联系邮箱与备用数据源。

# 阶段总结：PPT内容升级与模型降本增效

## 这段时间主要做了什么

这一阶段并不是在做PPT文件的自动排版，而是在完善“研究主题输入后，系统如何形成一套有内容、有深度、可用于学生汇报的PPT内容包”。最终交付包括：每页标题、上屏文字、配图建议、图片或资料入口、Vancouver简短引用，以及采用学术答辩语域的简短讲稿。学生可将内容复制到自己的模板中，因此暂不承担高成本的PPTX装配。

工作可以归纳为两条主线：一条提高内容质量，另一条降低模型调用成本和失败浪费。

## 一、PPT内容质量升级

### 1. 从固定目录改为动态研究框架

系统先判断主题属于疾病、治疗、诊断、技术、机制、工程、比较评估或转化产业化中的哪一类，再生成对应的研究问题和故事线。不同主题不再套用相同目录。

高级模型用于理解用户意图、聚焦题目和形成整体研究框架，因为这一步决定后续检索和表达方向；普通模型用于权威资料检索、证据抽取和格式化工作。

### 2. 从“面面俱到”改为围绕一个中心问题深入展开

真实试验发现，宽泛标题容易产生多条彼此平行的故事线。现在P1会判断题目是否过宽，给出聚焦标题、唯一中心问题和明确排除项；P2只保留服务于中心判断的研究问题。深度体现在选定方向内，而不是通过增加更多方向表现专业。

### 3. 从论文罗列改为研究叙事

每一页需要回答一个明确问题，并沿着“为什么值得研究—现有证据说明什么—不同研究能否比较—结论适用于什么条件—下一步问题是什么”推进。页面不再只是文献摘要或通路名词集合。

### 4. 配图必须服务于结论

配图建议需要说明应当寻找什么图、它回答什么问题、来自哪篇论文或权威页面，并提供可打开的入口。不能虚构论文图片，也不能用装饰性图片替代证据。

### 5. 讲稿由审计口吻改为学术答辩口吻

讲稿需要专业、连贯、能够自然讲给老师和同学听。普通页面不重复朗读“证据不足、未核实、开放问题”等内部审计术语；真正会改变解释的限制用一句专业判断交代，系统性局限集中在专门页面。与此同时，仍禁止虚构数字或来源。

## 二、模型选型与降本增效

### 1. 将高级模型放在高价值节点

高级模型主要负责用户意图、研究框架以及疗效、因果、安全性和审批等高风险声明的核验。普通模型负责检索结果筛选、证据抽取、普通声明核验和结构化输出。不是所有环节都使用高级模型，也不为了省钱把决定全局质量的框架工作交给低级模型。

### 2. 建立逐调用成本账本

每次调用记录模型、阶段、成功或失败、输入Tokens、推理Tokens、正文Tokens、总Tokens和人民币费用。每轮任务结束后必须复盘：每个阶段花了多少、哪些费用没有产生有效结果、能否通过工程规则避免。

### 3. 建立任务级硬停止

系统在请求发出前预估下一次最大费用，并按照任务总金额、总Tokens、Pro调用次数、Pro输出Tokens和Pro总Tokens进行停止。预算不是事后提醒，而是请求前阻断。

### 4. 缩小失败的影响范围

筛选按小批处理，证据按来源保存，核验按声明小批处理。某一批失败时只重跑缺失部分，不从P1重新开始。各阶段产物持续保存，可从检查点恢复。

### 5. 用确定性规则替代不必要的模型重试

不存在的证据编号、声明动作不一致、重叠删除、空标签、重复标点和引用格式转换等问题由程序处理。4xx和合同确定性错误不再原样重复调用模型；网络错误只在未产生Tokens时有限重试。

## 三、已经完成的真实主题验证

### 聚焦疾病机制主题

心脏瓣膜钙化主题验证了：聚焦后的故事线能够保留研究深度，同时避免机制、模型、药物和临床进展全部平铺。它也推动了页面文字密度、图片定位和讲稿表达规则的升级。

### 诊断评价主题

cfDNA甲基化多癌早筛主题验证了：动态框架可以从疾病机制切换到诊断评价，围绕目标人群、金标准、敏感性与特异性、外部验证和偏倚展开。该轮实际费用为¥0.7472，比此前聚焦轮次的¥0.8812下降15.2%，同时暴露并修复了输出截断、核验批次不完整和终稿装配可读性问题。

### 治疗与微环境主题

Claudin18.2 CAR-T晚期胃癌调查报告验证了报告专用链路：跳过PPT生成，仅运行研究框架、检索、证据、报告、声明核验和终稿装配。实际费用¥0.6105。工程链路通过，但科学审查发现来源仅3条且以综述为主，因此报告被明确标记为验证稿，没有把“零高风险残留”误判为“证据充分”。

## 四、这一阶段形成的核心判断

1. PPT内容包的价值首先来自研究问题和故事线，而不是页面数量或视觉装配。
2. 高级模型最应该投入在意图判断、整体框架和高风险核验，而不是所有机械步骤。
3. 内容质量、安全核验和面向用户的表达是三个不同层次，必须分别检查。
4. 总成本降低不代表工程效率一定提高，还要查看失败费用占比、重复调用和零结果调用。
5. “没有不支持声明”不等于“证据充分”；深入交付还需要来源数量、原始研究比例和问题覆盖率门禁。
6. 正式预算应根据通过质量门槛的真实运行分布制定，不能用模型最大Tokens直接当作单题预算。

## 五、当前交付形态

首版产品交付研究报告和PPT逐页内容包，不直接生成PPTX。PPT内容包包含：

- 聚焦标题和完整故事线；
- 每页目的、上屏文字和学术答辩讲稿；
- 配图类型、图片定位线索及原文入口；
- 关键声明、来源和Vancouver引用；
- 证据边界、局限与下一步研究问题；
- 本轮调用成本、失败与工程复盘。

## 六、后续工作

1. 用修正后的精确检索和来源结构门禁重新验证治疗类调研报告。
2. 继续扩大跨主题样本，形成稳定的单题成本分布和正式预算。
3. 将来源覆盖、原始研究比例和关键问题直接证据纳入生产验收。
4. 完成线上部署所需的访问控制、计量一致性和运营界面。
5. 在内容链路稳定之后，再评估模板化PPTX装配，不提前承担视觉生成成本。

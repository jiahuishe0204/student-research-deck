# 十条关键声明模型选型实验计划

## 目标

在同一组10条声明、同一组证据和同一评分标准下，比较全Flash、全Pro-low和混合路由。目标是在科学质量达到合格线后选择成本更低、失败更少、输出更短的方案，同时把PPT文字密度纳入产品验收。

## 初始验收标准

科学质量总分100分：支持状态30分、处理动作20分、有效证据20分、关键问题类型10分、解释与修订必要信息10分、结构稳定性10分。总分至少85分；支持状态至少8/10；处理动作至少9/10；严重错误和虚构证据必须为0。

严重错误包括：把专家参考答案中的“不支持”或“无法判断”判为“支持/保留”；引用输入中不存在的证据编号；删除关键安全限定而没有替代表述。

三种方案合计费用硬上限暂定¥0.45。达到上限时停止，不为凑齐结果追加调用。

PPT密度初始标准：全稿平均不超过180字/页；单页不超过220字；单条上屏文字不超过80字；每页不超过5条；备注不超过350字。科学限定语优先进入备注或附录，不能直接删除。

## 固定样本

5条强推理声明：CLM-0003、CLM-0008、CLM-0014、CLM-0021、CLM-0045。

5条普通但困难的声明：CLM-0030、CLM-0041、CLM-0060、CLM-0069、CLM-0074。

样本覆盖因果过度、疗效条件缺失、错误证据编号、跨宿主外推、通用流程外推、来源错配、摘要证据边界和不可核验的元陈述。

## 执行计划

1. 冻结声明、证据与专家参考答案。
2. 自动评分器先通过离线测试。
3. 依次执行全Flash、全Pro-low、混合路由；每种最多一次格式重试。
4. 记录每次输入、输出、reasoning、缓存、失败和人民币费用。
5. 先按科学质量淘汰，再比较成本、失败率和长度。
6. 对现有12页PPT运行密度检查，列出超限页面。
7. 一审科学判断，二审成本和稳定性，三审PPT呈现；真实问题反向修订规则，但不在看见结果后偷偷修改本轮参考答案。

## 首轮现实反馈与计划修订

全Flash得到79分并出现一项严重错误，不合格。全Pro-low在第一请求前被¥0.15金额停止器拦截，说明该方案在初始预算内不可行。混合方案中Pro的2,200 Tokens再次全部被reasoning占用，没有正文。

不修改专家参考答案，不重跑Flash，也不为全Pro追加预算。只对混合方案做一次参数修订：Pro批次至少允许4,000输出Tokens，仍使用low思考；追加实验金额硬上限为¥0.25。首轮实际¥0.1221，两轮理论合计不超过约¥0.3721。

修订混合方案仍因人民币预留停止。复盘Flash严重错误发现，引用证据裁剪使模型无法看到同一来源中的正确相邻证据。规则进一步修订为：普通声明只发送引用证据；中高风险强声明额外发送同源证据，用于发现证据编号错位。新增一次增强Flash运行，硬上限¥0.15；不再追加Pro实验。

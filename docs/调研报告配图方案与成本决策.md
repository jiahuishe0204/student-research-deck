# 调研报告配图方案与成本决策

## 结论

深度调研报告需要信息型图片，但不应机械执行“每节一张”。默认产品采用“正文括号内推荐图片、说明用途、提供精确原图网址并标记许可状态”；自动嵌图作为许可核验通过后的增强功能。

## 三种交付方式

### 1. 自动获取并嵌入图片

- 交付效果：最好，用户拿到即可阅读。
- 模型费用：已有结构化图表记录时可为零；下载、排版、图注和署名可以程序化完成。
- 额外成本：需要许可证核验、文件下载与存储、图片清晰度和版式检查；如果使用视觉模型裁切或解读，还会产生尚未纳入当前账本的费用。
- 主要风险：免费阅读不代表允许复制；开放获取论文也可能含不在开放许可证范围内的第三方图片。
- 适用条件：许可证明确、署名完整、图片与本节结论直接相关。

### 2. 只提供原图链接

- 交付效果：版权和系统实现风险最低，但用户不知道为什么要用这张图、应放在哪里。
- 模型费用：零；本轮证据抽取已经保存图号和网址。
- 用户成本：较高，需要自行判断图片用途和插入位置。

### 3. 推荐图片、用途和原图链接

- 交付效果：在完整度、成本和风险之间最平衡。
- 模型费用：默认零；从已有`figure_id`、图题、支持声明和章节映射确定性生成。
- 用户成本：只需打开网址、确认许可并决定是否插入。
- 推荐格式：`（推荐配图：……，原文 Fig. X；[打开原图页面](URL)；用途：……；复用许可：已核验/待核验。）`。不得使用紧接中文标点和说明文字的裸网址，以免浏览器把说明文字误判为网址的一部分。

## 数量原则

七个正文部分通常推荐三至五张信息型图片，而不是七张装饰图。优先覆盖靶点机制、核心疗效数据、安全性、生物标志物和关键机制；方法、解释边界与结论章节不必强制配图。

## 当前样本的实际成本

当前证据库已包含两条精确图表记录，因此给现有报告加入两条配图推荐没有新增模型调用，增量模型费用为人民币零元。自动嵌入同样可以不调用模型，但在完成许可证核验和版式质检前不应启用。若未来需要视觉模型识图、裁切或重绘，应先选择供应商与模型，再按实际输入、输出和图片计费写入逐调用账本，不能提前虚构价格。

## 工程停止规则

1. 没有精确图号或原图定位时，不下载、不嵌入。
2. 许可证未知时，只给链接并标记待核验。
3. 图片与章节不存在直接内容关系时，不为达到数量指标而推荐。
4. 同一图片重复命中时确定性合并，不重复处理或重复付费。
5. 只有内容理解不充分、无法确定图片与论点关系时，才允许进入模型判断。

# 产品与使用场景

版本：v0.1｜日期：2026-09-24

## 1. 背景洞察

人的时间分配并不完全由“重要性”决定。多数人愿意把自由时间用在娱乐、社交和即时反馈上；面对重要工作，希望借助更好的工具提高效率和思考质量；面对不重要但必须完成的任务，则希望尽量省时省力，并保持交付体面。

本产品不预设每个学生都热爱科研、想读博或愿意系统训练研究能力。它承认两类正当需求：

- 本科生面对低价值课设、课程展示或临时作业，希望快速完成一份结构完整、看起来认真、来源可靠的成果，把时间留给更重要或更喜欢的事。
- 研究生面对陌生方向，希望快速完成初步调研，建立技术框架、关键问题和可信来源，再决定是否深入阅读。

内部产品原则可以概括为“省时、省力、体面地完成”；外部营销不使用“敷衍”“代做”“包过”等表述。

## 2. 核心交付

学生在这些场景中最想得到的通常不是长篇 Markdown，而是一份有思路、有条理、可以用于课堂或组会汇报的 PPT。

首版采用低成本的“PPT 内容包”，暂不直接生成 `.pptx`：

1. 总体叙事思路：这次汇报要回答什么，先讲什么、后讲什么。
2. 逐页规划：每一页的标题、目的、页面正文、建议图表或示意图。
3. 演讲者注释：在演讲者模式下可以直接照着讲的口语化讲稿。
4. 可能追问：老师可能问什么，以及依据现有证据如何回答。
5. 来源映射：每页使用哪些论文、专利或官方资料。

这样既接近“直接交差”，又避免首版承担模板排版、图表渲染、字体兼容和文件修复等额外成本。后续可以增加模板化 `.pptx` 生成作为高级版或加购项。

## 3. 核心场景

### 本科生课设快速完成

- 输入：课程题目、老师原话、汇报时长。
- 目标：在有限时间内形成完整框架和可讲内容。
- 默认交付：8—12 页 PPT 内容包、演讲者注释、核心来源。
- 产品版本：快速版。

### 本科生竞赛或保研材料准备

- 输入：竞赛方向、项目简介、个人关注点。
- 目标：补齐行业背景、研究意义、技术路线和项目依据。
- 默认交付：背景调研、路线比较、PPT 内容包、可能追问。
- 产品版本：深入版。

### 研究生初步调研

- 输入：导师给出的主题、已有假设或实验方向。
- 目标：快速识别关键问题、主要路线、代表性进展、限制和证据缺口。
- 默认交付：调研报告、路线比较、证据清单、PPT 内容包。
- 产品版本：深入版。

### 组会或汇报救急

- 输入：主题、听众、汇报时长、截止时间。
- 目标：优先保证叙事连贯、术语解释和可回答追问。
- 默认交付：短版 PPT 内容包和演讲者注释。
- 产品版本：快速版；加急只改变队列，不降低核验标准。

## 4. 两档产品

### 快速版：尽快完成

- 面向一般课设、短汇报和主题扫盲。
- 自动识别意图、基础规划、核心资料检索、简化核验。
- 输出 8—12 页 PPT 内容包和基础报告。
- 首轮测试价格：9.9—19.9 元/次。

### 深入版：经得起追问

- 面向研究生初调、开题、竞赛和重要汇报。
- 强化规划、比较维度、反证、冲突来源与引用复核。
- 输出完整报告、PPT 内容包、演讲者注释和追问清单。
- 价格尚未冻结：业务测试候选为 39.9、59.9、79.9 元；当前页面的“15.9 元起”只用于测试版本选择交互，不代表最终售价。

版本差异来自推理、证据和决策价值，而不是简单增加字数。

## 5. 输入体验

首页允许直接粘贴老师原话。除主题外，只保留三个可选问题：

1. 用在什么场合：课程展示、组会、开题、竞赛、保研/面试。
2. 需要讲多久：3、5、10、15 分钟或自定义。
3. 想要：尽快完成，还是深入分析。

系统先识别意图并展示一句话确认，例如：“你需要一份面向本科课堂、约 8 页、5 分钟可讲完的技术概览。”用户可直接确认或修改，不暴露模型参数和提示词。

## 6. 边界

- 不承诺成绩、获奖、保研或录取结果。
- 不生成虚假论文、DOI、专利号或实验数据。
- 不以用户身份伪造已完成的实验、访谈或阅读。
- 不宣传“代做”“包过”；公开文案强调辅助整理、研究与表达。
- 重要学术任务提示用户至少阅读核心来源和演讲者注释。

# 产品与使用场景

版本：v0.1｜日期：2026-09-24

## 1. 更新后的背景洞察

生命科学本科生和研究生经常拿到一个较宽的主题，却不知道应该从机制、技术路线、疾病应用、实验方法、临床转化、专利或产业进展中的哪一条主线展开。普通大模型可以回答单个问题，但需要用户自己持续追问、筛选来源、组织结构和检查引用；真正困难的不是生成更多文字，而是把一个主题收敛成合适的研究方向，再形成证据一致的报告和汇报内容。

本产品不把“老师临时给了一句话”作为唯一入口，也不替用户决定最终研究题目。用户可以主动输入自己选择的主题；当主题过宽时，系统给出若干不同焦点及其差异，由用户选择后再开始深度调研。老师要求、课程约束、汇报时长和已有方向只是可选补充条件。

产品服务两类正当需求：

- 本科生需要完成课程展示、科研训练、竞赛背景或陌生主题汇报，希望得到结构完整、来源可靠、能够讲清楚的成果。
- 研究生需要快速进入一个方向，建立主题特异的研究框架、主要路线、关键证据和资料入口，再决定下一步实验或深入阅读。

产品的核心价值已经从单纯“省时完成任务”升级为“帮助用户选对研究焦点，并把证据组织成能读、能讲、能继续修改的专业交付”。省时、省力仍然重要，但不能以牺牲研究问题、证据质量和叙事逻辑为代价。

## 2. 核心交付

产品固定交付两种同源成果：一份完整、正常、专业的调研报告，以及一份面向课堂、组会、答辩或竞赛的PPT逐页内容包。两者使用同一套证据，但承担不同任务：报告负责完整论证，PPT内容包负责传播和讲述。

首版采用低成本的“PPT 内容包”，暂不直接生成 `.pptx`：

1. 总体叙事思路：这次汇报要回答什么，先讲什么、后讲什么。
2. 逐页规划：每一页的标题、目的、页面正文、建议图表或示意图。
3. 演讲者注释：在演讲者模式下可以直接照着讲的口语化讲稿。
4. 可能追问：老师可能问什么，以及依据现有证据如何回答。
5. 来源映射：每页使用哪些论文、专利或官方资料。

这样既接近学生真正需要的可用交付，又避免首版承担模板排版、图表渲染、字体兼容和文件修复等额外成本。后续可以增加模板化 `.pptx` 生成作为高级版或加购项。

## 3. 核心场景

### 本科生课程调研与汇报

- 输入：学生选择的主题；可选补充课程要求和汇报时长。
- 目标：从合适方向切入，在有限时间内形成完整报告和可讲内容。
- 默认交付：基础调研报告、PPT内容包、演讲者注释和核心来源。
- 产品版本：快速版。

### 本科生竞赛或保研材料准备

- 输入：竞赛方向、项目简介、个人关注点。
- 目标：补齐行业背景、研究意义、技术路线和项目依据。
- 默认交付：背景调研、路线比较、PPT 内容包、可能追问。
- 产品版本：深入版。

### 研究生初步调研

- 输入：学生选择或导师建议的主题、已有假设或实验方向。
- 目标：先确认具体研究焦点，再识别关键内容、主要路线、代表进展、限制和证据缺口。
- 默认交付：调研报告、路线比较、证据清单、PPT 内容包。
- 产品版本：深入版。

### 组会或汇报救急

- 输入：主题、听众、汇报时长、截止时间。
- 目标：优先保证叙事连贯、术语解释和可回答追问。
- 默认交付：短版 PPT 内容包和演讲者注释。
- 产品版本：快速版；加急只改变队列，不降低核验标准。

## 4. 两档产品

### 快速版：尽快完成

- 面向一般课设、短汇报和主题扫盲。
- 自动识别意图、基础规划、核心资料检索、简化核验。
- 输出 8—12 页 PPT 内容包和基础报告。
- 首轮测试价格：9.9—19.9 元/次。

### 深入版：经得起追问

- 面向研究生初调、开题、竞赛和重要汇报。
- 强化规划、比较维度、反证、冲突来源与引用复核。
- 输出完整报告、PPT 内容包、演讲者注释和追问清单。
- 价格尚未冻结：业务测试候选为 39.9、59.9、79.9 元；当前页面的“15.9 元起”只用于测试版本选择交互，不代表最终售价。

版本差异来自推理、证据和决策价值，而不是简单增加字数。

## 5. 输入与方向选择体验

首页以研究主题作为唯一必填内容。老师要求、课程限制、已有假设和汇报时长均为可选补充，不再把“老师原话”作为默认产品前提。

主题足够明确时，系统直接显示理解结果供用户确认。主题过宽、可以形成多个不同研究报告时，系统展示2—4个有实质差异的方向，每个方向说明：

1. 主要研究对象或中心内容。
2. 将重点展开哪些方面。
3. 适合课程概览、研究生初调、路线比较还是转化调研。
4. 哪些相邻内容不会在本次展开。

最终研究方向必须由用户确认。系统不能因为某一方向资料更多或生成更容易，就擅自替用户选题。

方向确认后，用户还可以补充三个可选信息：

1. 用在什么场合：课程展示、组会、开题、竞赛、保研/面试。
2. 需要讲多久：3、5、10、15 分钟或自定义。
3. 想要：尽快完成，还是深入分析。

系统展示正式题目、中心研究焦点和交付理解供用户确认，例如：“围绕导电水凝胶在周围神经电刺激中的材料设计、界面传导和功能恢复证据，形成深入调研报告与答辩式PPT内容包。”用户可确认或修改，不暴露模型参数和提示词。

## 6. 边界

- 不承诺成绩、获奖、保研或录取结果。
- 不生成虚假论文、DOI、专利号或实验数据。
- 不以用户身份伪造已完成的实验、访谈或阅读。
- 不宣传“代做”“包过”；公开文案强调辅助整理、研究与表达。
- 重要学术任务提示用户至少阅读核心来源和演讲者注释。

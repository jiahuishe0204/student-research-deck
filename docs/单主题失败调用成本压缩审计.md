## 可压缩费用

已经采取的措施：P2深入版改为 Pro medium；P4、P6和P8结构化阶段关闭隐藏思考；P8 Pro只负责高风险声明且使用受控短输出。历史浪费不应进入稳定生产预算。

### 2. 旧批次和旧输出上限：¥0.3722

P3大批量筛选产生计数不一致、重复来源和截断；P4、P5、P6使用固定输出上限，输出顶格后仍按原形状重试。

P7三次生成不存在的 evidence_id，费用¥0.0393；P8出现“不支持却保留”和“部分支持但没有实质降级”等动作错误，费用¥0.0265。这些错误不需要再次调用模型判断。

本次新增措施：P7在进入合同校验前过滤输入集合之外的证据编号并写入审计说明；P8根据支持状态确定性规范动作，不支持强制删除，无法判断强制标记未核实；部分支持却没有可用降级措辞时，保守转为无法判断并标记未核实。所有处理均失败关闭，不把问题声明错误放行。

# 流量投放与运营

版本：v0.1｜日期：2026-09-24

## 1. 获客不是先买广泛流量

首轮目标不是覆盖所有大学生，而是找到“此刻正被要求交一份调研或 PPT”的人。应优先进入已经聚集目标学生、掌握任务节点并具有信任关系的渠道。

渠道优先级：

1. 保研、考研复试、科研竞赛和背景提升服务机构。
2. 高校实验室、学生社团、课程助教、竞赛队和校园代理。
3. 小红书、B站、知乎、微信公众号等内容搜索场景。
4. 信息流广告与搜索广告，等自然转化和客单价验证后再扩大。

## 2. 机构合作策略

### 为什么机构是好入口

- 已经接触大量本科生和准研究生。
- 学生处于保研、复试、竞赛、科研入门等高意愿节点。
- 机构需要低成本的增值服务、资料工具和差异化卖点。
- 相比从零投放，合作方能提供信任背书和集中触达。

### 适合接触的机构类型

- 全国性考研辅导机构：学生量大，适合复试、专业理解和研究计划场景，但采购链条较长、合作决策慢。
- 垂直保研/背景提升机构：需求更贴近科研调研和展示，转化潜力高，但对交付质量和合规更敏感。
- 大学生创新创业竞赛辅导机构：天然需要行业背景、技术路线和答辩 PPT，场景高度匹配，但有明显赛季波动。
- 地方小型工作室和校园团队：决策快，适合首轮联营和白标测试，但规模有限、服务质量不一。

公开可验证的候选只作为商务线索，不代表已经建立合作：文都和海文覆盖考研辅导；保研岛公开提供保研、科研竞赛与背景提升服务；创赛岛定位大学生创新创业赛事辅导。正式接触前要逐一核对主体、口碑、合同和数据处理要求。

### 合作产品

- 兑换码：机构购买 50/100 次额度，发给学员使用。
- 联营分成：按实际付费订单结算，不收大额预付。
- 课程加购：作为复试、保研或竞赛班的“调研/PPT内容包”。
- 白标入口：后期提供机构品牌页，但首版不做深度定制。
- 教练工作台：顾问可查看学员提交的主题和交付状态，须取得用户授权。

### 首轮商务话术

不卖“AI工具”，卖机构现有服务的增值环节：学员把老师原话或比赛主题粘贴进来，快速得到有来源的调研框架、PPT逐页内容和讲稿，顾问可以把时间用在个性化指导和答辩训练上。

## 3. 内容获客

围绕具体任务时刻做内容，不做泛泛的“AI提升效率”：

- “导师说先调研一下，到底先查什么？”
- “5分钟组会汇报，8页PPT怎样安排？”
- “课程展示如何显得有逻辑，而不是堆资料？”
- “论文是真的，为什么仍然不能支持你的结论？”
- “保研面试被问研究方向，怎样快速建立框架？”

每篇内容提供一个可复制的小成果，例如第一页结构、追问清单或一页示例，再引导用户输入自己的题目体验。

## 4. 精准投放

### 受众与关键词

- 时间节点：开学课程展示、期中结课、夏令营、预推免、考研复试、挑战杯/创新创业比赛前。
- 搜索意图：调研报告怎么写、文献综述 PPT、组会汇报 PPT、科研竞赛背景分析、保研研究计划、技术路线对比。
- 专业优先：生命科学、医学、药学、生物工程；验证成立后再扩展材料、化学和环境。

### 素材原则

- 展示输入与交付物，不展示抽象模型能力。
- 展示“老师原话 → PPT逐页方案 → 演讲者注释”的前后对比。
- 不使用“包过”“保研必备”“一键代做”等承诺。
- 广告落地页按场景分开，避免所有流量进入同一个泛首页。

## 5. 运营漏斗

- 触达：看到场景内容或机构入口。
- 体验：输入主题，免费查看意图识别和前三页规划。
- 付费：解锁完整调研、PPT内容包、注释和来源。
- 交付：复制、Markdown导出；后续增加PPTX导出。
- 反馈：问“是否减少返工、是否能直接用于汇报、老师是否接受”。
- 复购：在课程节点或下次汇报前提醒；不做高频骚扰。

## 6. 首轮实验

### 实验 A：机构联营

- 找 3 家小型保研/竞赛机构，各给 20 个体验码。
- 对比机构顾问推荐与学生自助领取的激活率、付费率和交付完成率。
- 成功标准：体验激活率 ≥ 30%，完整付费转化 ≥ 8%，交付后“明显省时” ≥ 70%。

### 实验 B：内容投放

- 做 3 种场景素材：课程展示、组会救急、保研/竞赛。
- 每种素材使用同一预算和独立落地页。
- 先看“输入主题”的成本，不以点击成本作为最终判断。

### 实验 C：交付物偏好

- 同一份调研随机展示“报告优先”或“PPT内容包优先”。
- 比较支付率、导出率和完成时间。
- 预计 PPT 内容包优先更符合学生的直接交付需求，但必须用数据验证。

## 7. 核心指标

- 主题输入率：进入落地页后实际提交主题的人数比例。
- 意图确认率：识别结果无需大改即可确认的比例。
- 付费转化率：看到前三页规划后购买完整交付的人数比例。
- 交付成功率与中位等待时间。
- 复制/导出率和演讲者注释打开率。
- 返工率、退款率、老师/顾问接受度。
- 单次贡献毛利：价格减模型、检索、支付、渠道分成和售后成本。
- 30/90 天再次购买率；不强求月活。

## 8. 合规与品牌风险

- 与机构合作时明确这是研究与表达辅助工具，不冒充学校或教师官方服务。
- 明码标价，不做结果保证、虚假折扣和“包过”宣传。
- 用户上传的老师原话、草稿和研究主题默认按敏感学习资料处理，设置删除期限。
- 竞赛规则若要求作品独立完成，应提醒用户遵守赛事规定，不代替其完成核心创新与实验。
- 合作渠道不得未经同意获得学生报告内容；只提供必要的兑换与结算数据。

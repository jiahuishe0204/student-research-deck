# 无症状普通风险人群中cfDNA甲基化多癌早筛的临床效用证据评估：检测性能、癌种溯源与净获益的整合评价

## 故事线

本研究聚焦一个中心问题：在无症状普通风险人群中，cfDNA甲基化多癌早筛能否产生可验证的临床净获益。回答该问题需要一条完整证据链：筛查要在低患病率人群中以可接受的假阳性负担检出癌症（性能），阳性结果要被有效引导至正确诊断路径（溯源），最终必须证明筛查降低了癌症死亡率或晚期癌症发生率，且该降低不能被领先时间偏倚或过度诊断解释（硬终点），同时危害必须被量化。现有证据在前两个环节提供了有前景的中间指标，但核心硬终点证据尚未建立，因而尚不足以支持将MCED作为常规筛查推荐。

- 关键性能数据（ccga验证子研究、PATHFINDER）仅阅读摘要，未核验全文方法学细节（如失访、验证偏倚控制、敏感性定义）。

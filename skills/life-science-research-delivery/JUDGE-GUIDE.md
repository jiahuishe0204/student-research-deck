# 评委快速上手：生命科学科研调研 Skill

## 这个 Skill 做什么

它把用户给出的生命科学主题转成可追溯的调研报告、逐页 PPT 内容包和核验附录。研究流程覆盖意图与范围确认、检索计划、来源筛选、证据提取、报告与逐页内容撰写、关键主张核验和最终一致性检查。

本包是可移植的工作流程说明，不是独立应用：不会自行安装工具、携带密钥、调用作者网站后端或生成可下载 PPTX。运行时由评委所用代理环境的模型执行。

## 推荐主题范围

适用于生命科学、医学、生物技术、药学、生物工程及相关转化研究。为得到可核验的结果，建议提供一个明确对象、场景或比较维度，例如：

- “慢性植入神经接口的长期稳定性：材料、失效机制与动物/临床证据”
- “3D 生物打印类器官心脏瓣膜：制造策略、功能验证与转化瓶颈”
- “单细胞 RNA 测序在肿瘤微环境研究中的应用：方法比较与证据边界”

宽泛主题会先给出 2–4 个不同方向供用户选择，不会未经确认就自行收窄。此 Skill 不提供患者个体诊断或治疗建议，也不替代临床、专利或领域专家审查。

## 导入和发起任务

1. 解压本包，将 `life-science-research-delivery` 文件夹导入代理产品的 Skills/技能位置。若产品提供“上传 Skill/导入 ZIP”，可上传本压缩包；若要求手动安装，则复制整个目录，不能只复制 `SKILL.md`，因为流程细节和示例也在子目录。
2. 确认该代理会话启用了网页搜索。若需要专利检索，还要在同一个代理会话启用并授权 Zhihuiya/Patsnap 专利 MCP。
3. 在对话中给出主题、目标读者、希望的报告深度、时间范围或地域限制，以及需要报告、逐页 PPT 内容包还是两者都要。
4. 对宽泛主题先确认 Skill 提出的研究方向，再继续完整调研。

可直接使用的发起语：

> 请按 Life-Science Research Delivery Skill 调研“3D 生物打印类器官心脏瓣膜”。面向生命科学研究生，重点比较制造策略、功能验证和转化瓶颈；优先近五年研究，同时保留奠基性研究。先确认范围和研究计划，再使用本会话可用的网页搜索查论文与官方来源；若专利 MCP 可用，再单独检索专利。请交付中文调研报告、逐页 PPT 内容包和主张核验附录，并标出来源访问级别及未解决的问题。不要声称生成了 PPTX。

## 工具权限

- 网页搜索：用于发现和核对公开论文记录、官方数据库/监管/资助来源。代理应打开并核对底层来源，搜索摘要不能单独作为证据。
- Zhihuiya/Patsnap 专利 MCP：可选，用于专利记录和技术活动线索；必须与科学论文证据分开标注，专利不能证明疗效、安全性或同行评审结论。
- 模型/API：使用目标代理环境当前选定的模型。导入本 Skill 不要求提供 DeepSeek API Key，也不会自动调用项目网站现有的 DeepSeek API。
- 文件导出：只有代理环境确实提供文件创建/导出能力时，才能实际生成文件；无此能力时返回可复制的 Markdown 内容，并如实说明。

## 未授权、失败或无结果时的行为

- 没有网页搜索：不得声称做了实时检索；可请评委启用搜索或提供文献，也可仅给出明确标注的研究计划草稿。
- 没有专利 MCP：如果主题仍可用公开论文完成，继续科学文献调研，但明确写明“未进行专利检索”；若专利覆盖是任务必要条件，则先请求授权/配置。
- 工具报错、限流、无结果或权限不明：如实报告实际情况和已尝试范围；必要时建议缩窄/改写检索式。不得编造来源、假装工具调用成功，或把专利结果替代论文证据。
- 可能产生付费调用但额度/成本不明：先说明并取得用户同意，不继续扩大调用。
- 任何情况下都不要要求用户把密钥贴到聊天、网页搜索框或交付材料中。

## 手动验收标准

导入后用上述示例主题跑一次。检查代理是否：

1. 先明确范围和研究问题，再开始检索；主题过宽时等待用户选方向。
2. 实际使用可用的网页搜索；如调用专利 MCP，能将专利与论文分开呈现。
3. 为关键事实提供可打开的来源、稳定标识/URL、访问级别和对应证据，不凭摘要假装读过全文。
4. 输出报告、逐页 PPT 内容及核验附录，且数值、术语和证据强度彼此一致。
5. 工具缺失或失败时明确披露，不虚构调用、来源或 PPTX 文件。

该手动验收目前尚未在独立评委账号/代理环境完成。项目后端已有的真实 MCP/P1–P9 测试是相关实现的证据，但不能替代评委环境导入后的 Skill 行为验收。
